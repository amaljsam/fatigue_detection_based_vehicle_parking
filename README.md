# Fatigue Detection System

This is a **Fatigue Detection System** built using Python. The system detects driver fatigue or drowsiness based on real-time face analysis, including eye and facial landmark tracking, using machine learning libraries like **dlib** and **OpenCV**.

## Features

- **Face Detection**: Uses **dlib** to detect and track faces in real-time.
- **Fatigue Detection**: Identifies signs of fatigue, such as blinking rate and eye closure, using facial landmarks.
- **Real-time Alert System**: Sends an alert if the user shows signs of fatigue, helping to prevent accidents.
- **Cross-platform**: Works on Windows, Linux, and macOS (with minor adjustments).
